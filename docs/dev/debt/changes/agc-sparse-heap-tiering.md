# libSceAgcDriver

## add Opt-in draw paths

- [Tiered sparse heaps](../../../core/libs/prx/libSceAgcDriver/Graphics/src/GuestBufferMemory.cpp) (`APS5_TIERED_HEAPS`) - opt-in. An address-based build splits a releasable registered heap at least `APS5_TIERED_HEAP_MIN_MIB` (512) large that it cannot import whole, fully committed or committed on demand, into the host import window cells (64 MiB), in place of the prefix import `budgetedImportPieces` makes for a fully committed heap. A window is placed once its committed pages first hold a non-zero 64 KiB block (until then the mirror serves it from its zero block), each placement counting the whole window, and keeps its place: in the heap mirror while the tiered windows placed there fit `APS5_TIERED_HEAP_VRAM_MIB` (by default the device-local heap's reported budget less an eighth, less its usage other than the tiered heaps' mirrors), or in host imports of its committed pages after that; a window whose mirror already holds blocks stays in the mirror. An import the host import budget refuses is tried again evicting imports idle for two frames, as the address copy cap does. The mirror binds no blocks for imported pages, so it holds only the windows placed in it and the committed pages whose import was still refused; those stay in the mirror and are imported again only once the heap's committed pages outside the mirror windows change or an unplaced window gets data, and blocks bound before a page was imported stay bound. Nothing moves a window between the mirror and imports afterwards: a game whose hot data lies in windows first committed after the budget filled reads it over PCIe. A descriptor-bound buffer crossing a window edge dissolves the address space and is copied per build, as for a heap split by the host import budget. Joined heaps are not tiered. The window size, the 512 MiB threshold and the eighth are choices, not measured; the setting was tried on NVIDIA's Windows driver only.
