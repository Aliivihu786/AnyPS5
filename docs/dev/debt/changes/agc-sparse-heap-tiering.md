# libSceAgcDriver

## add Opt-in draw paths

- [Tiered heaps](../../../core/libs/prx/libSceAgcDriver/Graphics/src/GuestBufferMemory.cpp) (`APS5_TIERED_HEAPS`) - opt-in; tried on NVIDIA's Windows driver only. A releasable heap of at least `APS5_TIERED_HEAP_MIN_MIB` (512) that an address-based build cannot import whole is split into 64 MiB windows instead of `budgetedImportPieces`' prefix import. A window is placed when its pages first hold a non-zero block: in the heap mirror while the mirror windows fit `APS5_TIERED_HEAP_VRAM_MIB` (default: the device-local budget less an eighth and other usage), else in host imports of its committed pages. Placement counts whole windows and is first come, not by GPU use. Pages whose import the budget refuses after evicting idle imports stay in the mirror. A descriptor-bound buffer crossing a window edge is copied per build. Joined heaps are not tiered. The window size, 512 MiB and the eighth are not measured.
- [Tiered heap window moves](../../../core/libs/prx/libSceAgcDriver/Graphics/src/GuestBufferMemory.cpp) (`APS5_TIERED_HEAP_MOVES`) - opt-in. Hotness is the window's CPU write stamps, not GPU reads: a window the GPU reads every frame but the CPU never writes counts as cold. Every `APS5_TIERED_HEAP_MOVE_FRAMES` (8) frames one window moves: the least recently written VRAM window to imports while device-local usage is past its budget less an eighth, or an imported window written in the last 8 decisions back while two windows of headroom remain; a moved window waits 16 decisions. A demoted window's mirror blocks are released only once no region maps them, so while a cached shader resource holds one the VRAM is not returned. One move per decision, 16, 8 and two windows are not measured.
